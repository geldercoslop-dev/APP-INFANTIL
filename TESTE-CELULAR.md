# COMO TESTAR O APP NO CELULAR

## 1 - Rodar o projeto

```bash
npm run dev
```

## 2 - No terminal aparecerá algo assim

```
Network: http://192.168.X.X:5173
```

## 3 - Abrir esse endereço no celular
(os dois precisam estar no mesmo Wi-Fi)

## 4 - No celular abrir no Chrome

## 5 - Para instalar como aplicativo:

Chrome → menu → Adicionar à tela inicial
